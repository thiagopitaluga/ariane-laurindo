# Ariane Laurindo

Landing page da consultora imobiliária Ariane Laurindo, RE/MAX, com atuação em
Alphaville, Barueri e região.

## Destaques

- experiência mobile-first e CTAs direcionados ao WhatsApp;
- conteúdo para compra, venda e investimento imobiliário;
- SEO local, dados estruturados, sitemap e metadados sociais;
- galeria de imóveis, vídeos e prova de autoridade;
- acessibilidade, carregamento otimizado e respeito a movimento reduzido.

## Desenvolvimento

Requer Node.js 22 ou superior.

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
```
